# 交付前审查与修正

日期：2026-11-14。

## 范围与约定

本轮审查后台主要业务路径和管理界面，并执行仓库的完整业务测试及生产模式浏览器回归。沿用 Bun、Next.js App Router、React、Ant Design、Prisma / PostgreSQL 和既有黑白灰语义颜色，不更换技术栈或设计风格。

依据仓库 `AGENTS.md`、`README.md`、本地 Next.js Route Handler 文档及已有 UI 审查记录；UI 使用 `ui-audit`，按其要求读取布局、文案、排版、颜色、交互细节五项领域 Skill。未发现独立的项目设计系统规范。

覆盖后台 14 个入口：运营概览、订单、商品、兑换码、导入批次、用户、钱包相关订单、邀请收益、提现、支付与服务、网站设置、角色权限、操作日志、风控记录。业务回归覆盖账号检查与报价、组合付款、收款幂等、库存占用与履约恢复、退款、邀请结算、提现、RBAC、认证与敏感数据保护。

已有返佣等级相关未提交修改被保留，并随本轮测试验证。验证使用独立 `_test` 数据库中的随机 schema；没有修改现有 `.env`，没有向真实渠道发起扣款、退款、发信或兑换。
