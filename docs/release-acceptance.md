# 发布前验收记录

验收日期：2026-11-15。

后续按“真实数据库部署后的页面与功能”范围完成的验收见 [真实 PostgreSQL 部署验收](postgres-deployment-acceptance.md)：独立真实数据库、生产构建、web/worker、浏览器交易流程和服务重启持久化均已验证。真实支付渠道仍属于下文另列的正式上线检查范围。

范围为账户、安全设置、钱包充值、套餐购买、订单售后与管理后台。技术栈为 Next.js 16.4.6、React、Ant Design、PostgreSQL 18 和 Better Auth，沿用现有 CSS 变量、组件和中文文案。依据项目 `AGENTS.md`、`README.md`、订单与服务、库存、邀请提现、风控文档及实际实现进行检查。

本次使用独立临时 PostgreSQL 实例及测试 schema，运行生产构建的本地演示环境。没有执行真实扣款、退款、提现或生产部署。以下“通过”均指明确列出的测试范围，不能替代真实渠道联调。

统计口径：套餐成交金额包含当前状态为 `processing/completed/needs_session/failed` 的套餐订单，不包含钱包充值、未付款、取消及已退款订单；七日图按创建日期分组，包含当天。它是经营统计，不是支付渠道的结算账单。异常数包括失败、待更新会话，以及处理中但需人工处理或结果不确定的订单。

“行业主流功能”不是无限功能清单。本次确认的是上述交易与安全核心闭环；以下常见增强能力当前没有完整自助界面，不应宣传为已支持：

- 登录设备明细及逐设备退出：当前支持一次退出其他设备。
- 自助修改邮箱、账号注销及个人数据导出：当前通过支持邮箱处理账号请求。
- 用户自助发起退款/工单：当前通过支持核实后由后台处理。
- 后台按日期/状态组合筛选及财务报表导出：当前提供已有搜索、分页、记录与经营统计。
- MFA 恢复码：项目明确采用邮箱/Passkey 恢复路径，不提供恢复码。

这些能力是否为首发必需，应根据产品承诺决定；本报告没有把未实现项计入通过范围。
