# SEO 与统计

## 站点与搜索

- 构建和运行时设置 `APP_MODE=live` 及 HTTPS 的 `APP_URL`；演示模式禁止索引，sitemap 为空。
- 在后台维护真实商品名称、价格、说明、支持邮箱和账号操作指引。
- 可配置 `GOOGLE_SITE_VERIFICATION`、`BING_SITE_VERIFICATION`，重新构建后到搜索平台验证域名并提交 `/sitemap.xml`。
- 首页、套餐详情、对比、升级及帮助页可索引；账户、订单、结算和后台保持 noindex。

## 站内统计

后台展示最近 30 天的浏览、验证、报价、下单、付款、交付与退款计数，按来源分类。各阶段是独立活动计数，不代表同一批访客的严格转化率；钱包充值不算套餐成交。

浏览阶段尊重 DNT/GPC，不采集邮箱、账号 Session 或支付凭据。worker 定期清理超过 90 天的统计明细。

## Google Analytics 4

设置 `NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX` 后重新构建，构建与运行配置保持一致；空值或无效值不加载。演示和测试环境留空。

启用前在 GA4 数据流中关闭整个「增强型衡量」，不要额外开启表单或用户数据自动采集。应用自行发送页面浏览，移除查询参数和动态订单、商品标识，不发送表单内容、订单金额或购买事件。DNT/GPC 开启时不加载 GA。

启用后用测试属性检查实时报告，确认导航计数和上报字段符合预期。

## 在线客服

在「网站设置 → 服务联系」填写 Tawk.to 的 Property ID、Widget ID 并开启客服，完整刷新页面后生效。语言、欢迎语和在线时间在 Tawk.to 后台维护。

本站不主动向客服组件传递邮箱、Session、卡密或订单内容；Tawk.to 自身会处理访问页面、设备和聊天信息。支持邮箱作为独立联系入口保留。
