# 邀请返现与提现

## 返现规则

| 等级       | 有效邀请人数 | 默认返现比例 |
| ---------- | ------------ | ------------ |
| 邀请新星   | 0–4 人       | 3%           |
| 分享达人   | 5–19 人      | 4%           |
| 推荐官     | 20–49 人     | 5%           |
| 邀请合伙人 | 50 人及以上  | 6%           |

后台可修改名称、门槛、比例和结算期，比例上限 9%。用户管理支持指定等级或恢复自动计算。

仅直接邀请有奖励。默认每笔符合条件的成功交付套餐订单返现，可开启仅首单返现。自邀和钱包充值不返现。有效邀请按成功交付且佣金已结算的联系邮箱去重，游客也计入。

每笔订单锁定返现比例和结算规则；后台修改只影响新订单。退款会冲回佣金并重新计算有效邀请数。

## 提现额度

消费余额仅用于购买，只有已结算邀请收益可提现：

```text
可提现 = max(0, 已结算邀请收益 − 已打款金额 − 申请中冻结金额)
```

待结算收益、钱包充值和退款不计入提现额度。佣金冲回造成缺口时暂停新提现与打款登记。

## 渠道与处理

后台分别配置支付宝、微信和 USDT 的 Ethereum、Tron、BNB Smart Chain、Polygon 网络。每项有独立开关、起提金额、比例手续费和固定手续费；默认起提 ¥50、手续费为 0。

```text
手续费 = 四舍五入到分(申请金额 × 手续费比例) + 固定手续费
预计到账 = 申请金额 − 手续费
```

申请时填写金额、姓名和收款信息；USDT 还需选择网络、填写地址。申请冻结完整金额，保存费用快照；费用变化需重新确认。

管理员先受理申请，再实际转账并登记打款结果；系统不自动代付。拒绝申请需填写原因，并释放完整冻结金额。USDT 打款按申请网络和地址核对，登记实际数量及交易信息。
