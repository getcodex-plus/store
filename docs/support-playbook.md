# 客服处理

先请买家提供订单号，通过后台核对。不要索取账号密码、Session、验证码或完整卡密。站点的联系邮箱在「网站设置 → 支持邮箱」配置。

| 买家遇到的问题 | 怎么处理 |
| --- | --- |
| 已付款，订单仍待付 | 查渠道交易号、金额和订单状态。链上支付可请买家提供交易哈希；未核实前不要补单，也不要让买家再付一次。 |
| 已付款，尚未交付 | 查库存、采购和兑换进度。通常需要 10–30 分钟；超过 30 分钟仍未交付，转值班人，并在 2 小时内回复处理结果或下次更新时间。 |
| 页面要求更新账号信息 | 引导买家回到原订单提交，不要通过邮件或聊天接收凭据。上游结果不确定时不要重新兑换。 |
| 游客换设备后找不到订单 | 使用下单时的联系邮箱验证登录，再查看「我的订单」。核实归属前不要披露订单详情。 |
| 要求退款 | 先核对付款和履约结果，确认符合退款条件再办理。渠道退款 100% 人工处理，不承诺具体到账时间。 |

退款锁定及凭证登记见[取消与退款](orders-and-services.md#取消与退款)；超时提醒和主动回信时限见[订单巡检](ops-runbook.md#订单巡检)。
